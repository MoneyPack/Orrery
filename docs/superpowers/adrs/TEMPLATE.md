# ADR Template

Copy this file to `YYYY-MM-DD-<slug>.md` and fill in each section. Keep ADRs short — one decision per file.

**Date**: YYYY-MM-DD
**Status**: Proposed | Accepted | Superseded by <link>

## Context

What problem are we solving? What constraints bind the decision? Link the spec or plan that motivates this record.

## Decision

What did we decide? Name the exact files, interfaces, or behaviors.

## Consequences

### Positive

What improves because of this?

### Negative

What gets harder? What risk do we accept?

### Mitigations

How do we contain the negatives?

## Alternatives Considered

What else did we weigh, and why did it lose? One line each is enough.
